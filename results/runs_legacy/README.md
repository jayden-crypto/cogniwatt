# Legacy runs — pre-recalibration environment

`ff_2m/` is the run the currently published headline in `docs/r1_report.html`
and `docs/r1_results.md` was generated from. It is kept for provenance and is
**not** comparable to anything in `results/runs/`.

It was trained against an environment that no longer exists in this tree:

| | `ff_2m` (legacy) | current tree |
| --- | --- | --- |
| observation | 40-dim (`FEATURE_DIM = 5`) | 41-dim (`FEATURE_DIM = 6`, `memory_gb` added) |
| held-out devices | `coral_micro`, `rtx3060` | `jetson_nano_2gb`, `rtx3060` |
| `ent_coef` | 0.01 | 0.12 (raised during hardware recalibration) |

`policy.pt` therefore fails to load against the current `ActorCritic`:

```
size mismatch for enc.0.weight: checkpoint [128, 40] vs model [128, 41]
```

It is moved out of `results/runs/` so that `scripts/make_report.py` — which
globs that directory — cannot silently mix the two eras in one table. The
replacement canonical run is `results/runs/main_s0`, produced by
`scripts/r1_sweep.py`.

`results/eval/eval_*.csv` in the repo root are likewise legacy (they contain
`coral_micro`) and are regenerated by `scripts/evaluate_policy.py`.
